# 漫画工作台

漫画工作台用于把小说内容延展为漫画分镜、角色视觉资产和画面提示。它适合在小说已有稳定角色、世界和章节片段后使用。

## 适合什么时候打开

- 小说角色比较明确，想生成角色形象资料。
- 章节场景适合拆成分镜。
- 想把正文内容转成画面提示。
- 需要维护角色视觉一致性。
- 想为封面、宣传图或漫画化探索素材。

如果小说主线还没有确定，建议先完成开书方向、角色和第一章，再进入漫画工作台。

## 核心工作流

项目页顶部会显示「推荐下一步」引导条：完成一步后会提示下一步该做什么，并可一键跳到对应 Tab。

推荐顺序：

1. 导入内容源（小说 / TXT / 原创灵感）。
2. 生成分话大纲。
3. 为某一话生成分格脚本。
4. 生成角色三视图（出图前更稳）。
5. 在格子图批量出图（先选好图片供应商和模型）。
6. 导出长图或切片。

也可以随时备份整个漫画项目：在项目「导出」页下载备份文件，之后在漫画工作台用「导入备份」恢复为新项目（可选是否包含已生成图片）。

漫画工作台的重点是从小说或导入文本中继承信息，而不是脱离故事重新创造一套设定。

## 分镜怎么用

分镜适合把一段正文拆成连续画面。阅读分镜时关注：

- 每格发生什么动作。
- 出场角色是谁。
- 场景和镜头重点是什么。
- 情绪和冲突是否清楚。
- 是否需要保持前后角色外观一致。

如果分镜和正文不一致，优先回到小说内容或角色资料确认事实。

## 角色资产联动

漫画工作台应尽量复用角色库信息：

- 角色姓名和身份。
- 外貌基准。
- 服装和标志物。
- 性格和表情范围。
- 与其他角色的关系。

角色视觉资产越稳定，后续封面、分镜和插图越容易保持一致。

## 和小说主链的关系

漫画工作台属于衍生工坊，不应抢走小说主链的优先级。

推荐顺序：

1. 先确定小说方向和核心角色。
2. 生成前几章，确认世界和人物关系。
3. 从稳定章节中提取漫画素材。
4. 把视觉资产回填到角色或项目资料。

如果小说设定还在大幅变化，过早生成大量视觉资产会增加返工。

## 使用建议

从一章或一个场景开始试用，不要一次把整本书都转成漫画素材。先确认角色外观、画面提示和分镜质量，再扩大范围。

遇到图片效果不稳定时，先检查角色基准图、视觉描述和参考资产，再调整模型或提示。
