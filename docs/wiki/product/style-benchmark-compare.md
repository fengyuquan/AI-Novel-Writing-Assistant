# 章节编辑器：范本对照

## Background

写作新手写完一章后，很难判断“差在哪里”。如果手里有一本爆款范本，最有效的学习方式是：用同一章剧情，按范本手感另写一版，再逐段对照。

这与普通审校、AI 写法检测、局部改写不同：那些能力是修自己的稿；范本对照是**学习辅助**，不替代交稿。

## Decision

- 在章节编辑器提供「范本对照」入口。
- 学习范本支持三类来源：
  - 写法档案（常由知识库爆款提取）
  - 知识库文档正文样章
  - 另一本已有正文的小说项目
- Prompt 链路（AI-first）：
  - `novel.chapter_editor.style_benchmark_essence@v1`：先抽取可迁移「精髓卡」（声口/对话/节奏/镜头/忌用/指纹/样章锚点）
  - `novel.chapter_editor.style_benchmark_rewrite@v2`：按精髓卡整章仿写，并返回指纹覆盖情况
  - `novel.chapter_editor.style_benchmark_segment_rewrite@v1` + `unify@v1`：长章分段仿写后再统一声口
  - `novel.chapter_editor.style_benchmark_compare@v1`：按情节节拍对齐后逐段点评
- 仿写目标是「接近范文精髓的可核对手感」，不是通读整本范文；样章仍截断精选，精髓卡可按范文来源复用。
- 对照稿默认不写回章节正文；产品明确“只对照，不替换”。
- 对照结果落库到 `ChapterStyleBenchmarkCache`，与 `novelId + chapterId` 1:1 绑定；重开章节仍可恢复；缓存含 `essenceByReferenceKey`。
- 版本键为「学习范本 + 生成模型」：同一范文换模型会另存一版；同一范文同模型重生成才覆盖。
- 若库中无缓存而本机还有旧 `localStorage`，首次打开会自动迁移进库并清理本机副本。
- 对照窗按段落序号左右对齐（同一行对照同一段）；用户正文与 AI 范文均可编辑；范文编辑写回本章缓存。
- 段落切分以空行（双换行）为准；当左右段数/切段不一致时，用户可在单侧用「空出本段 / 并入上段」手动对齐，而不是依赖自动重切。
- 点选范文侧只切换聚焦范文与行高亮，不触发窗内滚动定位；只有点评区的「定位到对应段落」才滚动。
- 对照窗支持全屏、窗内定位到段落行、多标签切换、最多 4 列并排（默认 1 列，并排偏好可本机记住）。
- 手机对照工作台按「方向 + 高度」切换布局，而不是只看宽度：
  - 竖屏 / 窄宽：每段内单列堆叠（你的正文 → 已勾选范文），顶/底栏默认可收起为箭头；段号为横向导航。
  - 矮横屏（横置且可视高度约 ≤560px）：恢复多栏并排，列头显示版本，段落卡简化标签；段号为侧边细轨。
  - 手机同时对照范文上限 3 篇（另加用户正文）；输入框字号 ≥16px，段落行使用 `content-visibility` 减轻长章卡顿。
- 结果不得阻断自动导演主链。

## Current Rule

1. 入口：章节编辑器左侧「范本对照」。
2. 生成时先抽取/复用范文精髓卡，再仿写；面板展示「将学习」指纹与「已做到/未覆盖」；可按未覆盖指纹再生成。
3. 本章超过约 4000 字时走分段仿写 + 声口统一；短章仍一次仿写。
4. 可选不同学习范本多次生成；写好后自动打开对照窗。
5. 对照窗按段落行对齐：每一行是「你的第 N 段 | 范文第 N 段」；左右都可编辑。并排 1-4 篇范文时，同一行横向对照多篇。手机竖屏改为段内堆叠；矮横屏恢复并排。
6. 段落错位时：对本侧点「空出本段」在当前行前插入空段（后续下移）；点「并入上段」把当前段合并到上一行（空段则只删除空位）。只改被操作的那一列；对齐按钮与段标签同一行。
7. 「定位到对应段落」只在对照窗内滚到该行并高亮，不关闭窗口。点选范文正文/标签不触发该滚动。弱段可从段号导航或「下一段弱段」跳转。
8. 逐段点评按当前聚焦范文（主范文）执行；点评结果按 session 缓存。编辑该篇范文内容后清除其点评，需重新点评。
9. 从章节缓存恢复时不自动弹窗；可手动打开。清除会删库中本章缓存。
10. 手机打开对照时默认全屏工作台；顶栏/底栏可收起为单箭头，避免占高。
11. API：
   - `GET .../editor/style-benchmark/sources`
   - `POST .../editor/style-benchmark/rewrite`（可带 `focusGaps`）
   - `POST .../editor/style-benchmark/compare`
   - `GET/PUT/DELETE .../editor/style-benchmark/cache`

## Examples

- 用户导入爆款进知识库并提取写法 → 选写法档案 → 生成对照稿 → 逐段看开场压迫感差在哪。
- 用户库里已有一本范本小说项目 → 直接选该项目 → 用其样章手感写对照稿。

## Failure Modes

- 范本没有正文/写法信息 → 返回可理解业务错误，提示换范本或先提取写法。
- 对照仿写改了剧情 → Prompt 硬约束保持情节一致；`plotFidelityNotes` 用于自检说明。
- 点评按行号硬切、不对齐节拍 → Prompt 要求先对齐情节节拍；摘录必须可定位。
- 章节过长 → 服务层字数上限，提示精简后再对照。
