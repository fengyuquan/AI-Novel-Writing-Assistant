# AI 小说创作 · 命令行壳

这是一个**不改动网页界面**的命令行交互入口。它只调用现有后端 `/api`，和网页端读写同一套小说、导演任务与章节数据。

## 启动

先保证后端在跑：

```bash
pnpm dev
# 或只开后端
pnpm dev:server
```

再开命令行壳：

```bash
pnpm dev:cli
```

可选参数：

```bash
pnpm --filter @ai-novel/cli start -- --api http://127.0.0.1:3000/api
```

环境变量：

- `AI_NOVEL_API_BASE_URL`：API 根路径，默认 `http://localhost:3000/api`
- `AI_NOVEL_CLI_POLL_MS`：进度轮询间隔，默认 `3000`

## 能做什么

- 菜单跳转：创作环境、小说项目、自动导演、进度、章节、运行记录
- 问答输入：灵感、标题、模型配置、方案选择
- 进度提示：导演命令轮询、阶段百分比、可选 AI 实况订阅
- 修改故事规划：查看宏观规划摘要，用一句话反馈让 AI 完善/重做当前步骤，或优化文字大纲后保存

## 边界

- 不复制服务端业务逻辑，只做交互壳
- 复杂工作台编辑（世界观细调、提示词编辑器等）仍建议用网页端
- 与网页端并行使用时，看到的是同一本小说和同一导演任务
